1 · The use case

Enid watches the Northwind loan. In Q3, the auditor changes and a footnote quietly restates Q2's EBITDA down. The Q3 certificate still reads green. The question: does the agent notice that Q2 — already signed off — is now a breach?

A memoryless watcher sees

Only the Q3 certificate in front of it: leverage 6.36×, ICR 2.02× — both pass. Reports "all clear."

Memory should catch

That Q2 was tested at 5.90× on $50.0M EBITDA; applying the restated $43.0M gives 6.86×. Retroactive breach.
