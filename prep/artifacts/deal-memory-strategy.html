3 · The recommended play

"Seen This Movie Before." A judge changes one word on a document. Enid recognizes it from a past deal, runs the playbook it learned there, and catches a breach it had already blessed. Here's the sequence on stage.

Seed a prior deal Planned
Deal APEX-9: its auditor was downgraded, and two quarters later the borrower restated. Enid stored that as a lesson keyed to "auditor change."
The judge flips one field
On today's Q3 compliance cert, change the auditor from a Big-Four name to a regional firm. That's the whole input — unfakeable, judge-supplied.
The tripwire fires
Exact-match on the auditor name via trigger(). A playbook card slides in showing its steps and why (because, confidence, times seen) — the memory is visibly the actor, not a search box.
Step 1 runs: re-check last quarter
The playbook tells Enid to re-tie Q2's EBITDA against the amended financials.
The restatement supersedes
Q2 EBITDA $50.0M → $43.0M. Leverage recomputes 5.9× → 6.9× against a 6.50× covenant.
A green quarter turns red
Q2, previously COMPLIANT, flips to RETROACTIVE BREACH — with the superseded number and the now-falsified original cert shown.
The kill switch
Toggle memory off, replay the same flip: the name is just a name, no card fires, the old cert stays green. The break is total — proof the memory was load-bearing.

The recipe that works

Real · live acct

Same covenant restated to 4.0×. The only thing that changes is how the update is phrased.

✗ Amendment framing — no supersession
"...increased to 4.0× under the First Amendment"
active 3.5×   active 4.0×
reads as a new fact — both stay true, nothing to flip
✓ Canonical restatement — supersedes
"...covenant is 4.0×"
superseded 3.5× → active 4.0×  supersedes→old
/revisions returns the 2-node chain — the walkable trail

Works same-conversation and across quarters. Build rule: ingest the restated value as the same fact; keep "First Amendment" as on-screen flavor only.

5 · The crack is closed

✓ Greenlit — the brick is set

The follow-up probe settled it: the restatement does retire the old value and leave a walkable trail — the earlier failure was only phrasing. Confirmed live: old fact → superseded, new fact → active with a supersedes pointer, and /revisions returns the 2-node chain. The hero is buildable exactly as designed.

The one rule to hold: feed the restatement as the same canonical fact with a new value ("...is 4.0×"), never as an amendment narrative ("...increased to 4.0× under the First Amendment").

In the back pocket: the capacity ledger

Still worth keeping as a second beat or safety net: a borrower asks for a 3rd equity cure; Enid recalls "2 of 2 already used" and rejects it — a "compliant → default" flip needing only recall + arithmetic. Not needed to de-risk the hero anymore, but a clean bonus.
