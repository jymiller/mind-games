# Halveston Services — the second deal (the cross-deal link)

> **FICTIONAL — created for demonstration.** Every entity, person, date and
> figure is invented. Any resemblance to a real company, fund, firm or person is
> coincidental. Contains **no confidential, non-public or MNPI** information.

This is the **second** deal in the pack, and it exists for one reason: to prove
the kind of memory a single deal cannot. It is a *different* borrower, in a
*different* sector, with a *different* lender — but the **same sponsor**
(Ardenmoor Capital Partners) and the **same trick**: run-rate cost-synergy
add-backs that inflate earnings, are later disallowed, and tip a covenant into
breach.

And it happened **two years earlier** than the hero deal. So when the system
looks at Thornwick's 2026 breach, the honest, memory-powered observation is:
**"Ardenmoor has done this before."**

## The parallel, at a glance

| | Deal 1 — Thornwick (2026) | Deal 2 — Halveston (2024) |
|---|---|---|
| Sponsor | **Ardenmoor Capital Partners** | **Ardenmoor Capital Partners** |
| Sector | Logistics | Business services |
| Lender | Fenwater Credit Partners | Cindermoor Credit Partners |
| The trick | Run-rate synergy add-back | Run-rate synergy add-back |
| Add-back disallowed | £3.0m | £3.5m |
| Outcome | Compliant → **breach** on restatement | Compliant → **breach** on restatement |
| Then | Waived, covenant reset | Waived |

Same play, different year, different deal. That repetition is the whole point.

## The numbers that tie

## What's in this deal

- **`01-credit-agreement-excerpt.md`** — the leverage covenant (≤ 5.75×) and the
  EBITDA add-back definition. The add-back language is **the same** as
  Thornwick's — that's what lets the system recognise the pattern.
- **`02-compliance-certificate.md`** — Q2 2024, the earnings build with the
  £3.5m synergy add-back, leverage 5.38×, signed by the CFO, naming the auditor.
- **`03-restatement-note.md`** — the FY2024 audit disallows the synergies,
  restating leverage to 6.22× — a breach — subsequently waived.

## The memory beat this unlocks

Ask the system: **"Has this sponsor done this before?"** With only Thornwick, it
can't answer. With Halveston in memory — a separate deal it wasn't asked about —
it can: *"Yes. Ardenmoor's Halveston deal used the same run-rate-synergy add-back
in 2024; it was disallowed and breached the leverage covenant."* That retrieval,
across deals, by shared sponsor, is the thing a large context window cannot fake.
